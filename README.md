# Zippy E-Commerce Platform

Zippy is a full-stack quick-commerce e-commerce web application featuring live product browsing, multi-vendor order placement, Razorpay payment gateway integration, real-time WebSocket order tracking, and Cloudinary media management.

---

## 📁 Repository Structure

- **`zippy-frontend-main/`**: React + Vite + Tailwind CSS frontend web application (Configured for Vercel deployment).
- **`zippy-backend-main/`**: Express + Socket.io + Mongoose API server (Configured for Render deployment).
- **`DEPLOYMENT.md`**: Complete step-by-step deployment guide for Vercel, Render, and Neon / MongoDB Atlas.

---

## ⚡ Quick Start

### 1. Backend Setup
```bash
cd zippy-backend-main
npm install
npm run dev
```

### 2. Frontend Setup
```bash
cd zippy-frontend-main
npm install
npm run dev
```

---

## 🚀 Deployment Instructions

Refer to [`DEPLOYMENT.md`](./DEPLOYMENT.md) for full instructions on deploying:
- **Frontend** to Vercel
- **Backend** to Render
- **Database** to Neon (PostgreSQL) or MongoDB Atlas
